## 👋 About Me

Hi, I'm Nakhid — a **Senior Full-Stack Engineer** with **5+ years** of experience building and scaling **multi-tenant B2B SaaS platforms**. I work across the whole stack, with a strong focus on **Node.js / TypeScript / NestJS** on the backend and **React / Next.js / React Native** on the frontend, running on **AWS**.

My work centers on system architecture, distributed systems, database optimization, third-party integrations and CI/CD — and on helping teams (I've mentored up to **6 engineers**) ship secure, scalable, high-performance software.

> I take ownership end-to-end — from architecture decisions to production monitoring. I communicate clearly, document what matters, mentor when needed, and deliver without hand-holding.
